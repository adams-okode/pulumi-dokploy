## Modifications

The original SVG was sanitized for static web use: the decorative brown ellipse was removed, the whale path was retained, the fill was recolored to Dokploy blue (#126782), Illustrator/XML metadata and fixed dimensions were removed, and a responsive viewBox plus accessible title and description were added.
